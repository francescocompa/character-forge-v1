# `docs/`

- [`PROJECT-SCOPE.md`](PROJECT-SCOPE.md) — required reading for every task: scope,
  architecture decisions, design canon. The source of truth.
- [`DECISIONS.md`](DECISIONS.md) — decision log, D16 onward (D1–D15 are in
  `PROJECT-SCOPE.md` §3). Rejected options and verbatim notes, not just winners.
- [`DESIGN-SYSTEM.md`](DESIGN-SYSTEM.md) — the component-level skeleton: shared
  primitives, the micro-label voice, chip/icon conventions, and what's a
  deliberate divergence from monster-forge vs. what's still drift.
- [`INSTALL.md`](INSTALL.md) — installing the deployed PWA (iOS/Android/desktop) and
  its offline behavior.

Architecture overview and conventions now live in the [root `README.md`](../README.md)
and [`CLAUDE.md`](../CLAUDE.md); the contract itself is [`schema/`](../schema/README.md)
and the pipeline recipes are [`pipeline/`](../pipeline/README.md).
